# Contribuição e testes

- Mantenha alterações em branches e preserve `main` estável.
- Teste a interface com Foundry VTT 14.369 antes de marcar uma versão como validada.
- Execute `node --check scripts/main.js` para uma verificação inicial de sintaxe.
- Teste como GM e jogador: sincronização, permissões, janelas, persistência e migração.
- Não inclua informações pessoais nem dados de mundos de jogo no repositório.
- Nenhuma licença de distribuição foi escolhida neste pacote; o proprietário deve decidir
  se deseja publicar o código sob licença aberta.
